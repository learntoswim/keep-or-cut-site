# keep-or-cut-site

The public support and privacy pages for **Keep or Cut**, an iPhone app for
deleting photos you do not need.

Served by GitHub Pages from `main` at the repository root:

- Support — <https://learntoswim.github.io/keep-or-cut-site/>
- Privacy policy — <https://learntoswim.github.io/keep-or-cut-site/privacy.html>

Both URLs are referenced from the App Store listing, so they must stay
reachable at these exact paths for as long as the app is on sale.

Static HTML, no build step and no dependencies. The source of truth is
`docs/site/` in the app repository; changes are made there and copied here.
